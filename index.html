📋 How to Use This SWMS
  1. Fill in the Site Details section.
  2. Select all High Risk Construction Work (HRCW) types that apply to this job.
  3. Tick only the controls you will actually implement — do not tick everything.
  4. Complete all fillable fields within each control (distances, types, names). Leave no field blank.
  5. Brief all workers on every selected control before any work begins.
  6. Review all controls at the daily prestart. Stop work if any control cannot be maintained. Update the SWMS if conditions change.
  7. Save a version whenever the SWMS is updated so previous versions are preserved.
  8. Keep this SWMS accessible on site at all times. Retain for 2 years after any notifiable incident.

⚖️ SWMS Compliance — s.299 WHS Regulation Qld
How will compliance with this SWMS be ensured?
Brief all workers involved in the work on this SWMS — including all selected control measures — before any work begins. Workers must sign the acknowledgement section. Only workers who have been briefed may commence work.
How will control measures be reviewed and monitored?
Review all selected controls at the daily prestart to confirm they remain suitable for site conditions. STOP work immediately if controls are not in place or not being followed. Update this SWMS by deselecting controls that no longer apply and selecting replacements. Re-brief all workers on any changes and obtain new acknowledgements before recommencing work.
